# career-website

Public career site for Jithesh Pallikkara, planned for https://jitheshpallikkara.com.

A single static page (`index.html` plus `assets/`). There's no build step, so it runs on any static host.

## Deploy on Vercel

1. Sign in at https://vercel.com with GitHub and choose **Add New → Project**.
2. Import `jitheshpj/career-website`. Leave the framework preset as **Other** with no build command.
3. Deploy. Every push to `main` redeploys automatically.
4. Under **Settings → Domains**, add `jitheshpallikkara.com` and follow the DNS records Vercel shows.
